# Arena FPS

Jogo de tiro em primeira pessoa que roda no navegador (HTML + CSS + JavaScript + Three.js via CDN).
Sem instalação, sem backend.

## Controles
- WASD: movimentar (Shift corre)
- Mouse: olhar
- Clique esquerdo: atirar
- R: recarregar
- ESC: liberar o mouse

## Como jogar
Sobreviva a 5 ondas de inimigos. Tiro na cabeça causa o dobro de dano.
Ao fim de cada onda você recupera um pouco de vida e munição.

## Rodar
Abra o `index.html` no navegador (é preciso internet para carregar o Three.js) ou use o link do GitHub Pages.
